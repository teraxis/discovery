# AGENTS.md

Цей репозиторій — набір інструментів для досліджень у Google NotebookLM.

- **Встановлення й налаштування:** виконай [AGENT_SETUP.md](AGENT_SETUP.md).
- **Як користуватися:** прочитай [skills/discovery/SKILL.md](skills/discovery/SKILL.md). Це основна інструкція: які команди запускати, як вибрати тип дослідження, правила.

Принцип роботи — мінімум токенів:
- ти формуєш **одну** команду `nlm …` і запускаєш її;
- скрипт друкує короткий підсумок;
- великі результати (DOCX, журнали) не читай, якщо людина не попросить.

Вхід у Google (`nlm login`, `nlm drive-auth`) виконує тільки людина.
